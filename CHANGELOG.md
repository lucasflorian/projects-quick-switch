# Changelog

## 0.4.2

- README: clearer presentation and installation instructions.

## 0.4.1

- Source code published on GitHub.

## 0.4.0

- "Pinned" projects are now "Favorites" (star icon).
- The "Other Projects" section is hidden until you type a search. New `projectSwitcher.showOtherProjects` setting to always show it.
- The "Recent" section shows 10 projects by default (`projectSwitcher.recentLimit`).

## 0.3.0

- Outline version of the logo as the status bar and editor tab bar icon.
- New `parentNameBelow` option for `projectSwitcher.pathDisplay`: parent folder name below the project name.

## 0.2.0

- English interface, with French translation.
- Default shortcut is now `⌥R` / `Alt+R`, and a new `Projects: Change Keyboard Shortcut` command.

## 0.1.1

- First release.
